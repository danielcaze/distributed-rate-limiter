# Domain docs

This is a single-context repository. Read the root [`CONTEXT.md`](../../CONTEXT.md) before using domain terms in code, issues, or tests. It is a glossary, not an implementation spec.

Read relevant ADRs in `docs/adr/` when that directory exists. Create an ADR there only after a consequential, surprising trade-off is decided. If a term or ADR is absent, continue without an empty placeholder and update the glossary when a term is resolved.
